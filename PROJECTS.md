## Industrial Decision Support System

**Contribution:** SCADA data → SSIS ETL → SQL Server data warehouse → KPI calculation → Django analytics. The focus is data centralization, automated integration, dashboards, reporting and operational decision support. No quantified improvement is claimed.

## Pumping Station Performance Optimization

**Problem:** Assess operational performance and energy efficiency.

**Approach:** KPI inventory and selection, field measurements, thresholds and gap analysis using DMAIC, Ishikawa and 5 Why. Automated KPI calculation and Power BI dashboards support monitoring of energy ratio, efficiency, equipment availability and clogging rate. No quantified energy saving is claimed.

[Portfolio case study](https://portfolio-ach-bcbc.vercel.app/en/projects/pumping-station-performance)

## Automated Pumping Station Supervision

**Scope:** Automated operation and monitoring using an S7-1200 PLC, VFD and sensors, with day/night modes, pump rotation, chlorine monitoring, alarms and HMI supervision.

**Methods:** DMADV, functional analysis, FAST, GRAFCET, GEMMA and AMDEC. Deployment status and measured results have not been supplied.

## Airport Queue Simulation

**Purpose:** Capacity analysis, bottleneck detection, resource balancing and flow optimization using Arena, Input Analyzer and queueing theory.

**Results supplied for one simulation run:**

| Measure | Value |
| :--- | ---: |
| Simulation duration | 480 min |
| Passengers entered | 241 |
| Passengers exited | 109 |
| Average system time | 151.10 min |
| Average waiting time | 124.89 min |

Check-in and security were identified as bottlenecks. These are simulation observations, not measured improvements or live airport operating results.

[Related simulation portfolio case study](https://portfolio-ach-bcbc.vercel.app/en/projects/airport-queue-simulation)
